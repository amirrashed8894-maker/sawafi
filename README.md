# الصوافي
PWA offline لحساب صافي سعر البيع في السعودية راجع لمصر (العمولة، مصروفات البراد/الحاوية، النولون، المقارنة بتكلفة الطن، سعر التعادل).
الحساب (DEF / calc / _ld / f) منسوخ حرفيًا من البرنامج الأصلي (صوافي) — ممنوع تعديله. نفس مفتاح الحفظ `safiNetback.v2` (ومنقول من `safiNetback`).
اختبار: `node test/calc.test.js` — بعد تعديل style.css أو index.src.html شغّل `python3 build.py` (بيحط الـ CSS والخط جوه index.html عشان الـ PDF يطلع مظبوط من غير نت).
