# الصوافي والتكاليف (v2.0.0 — معاينة على فرع preview/merged-app)
برنامج واحد بثلاث أقسام على نفس الموقع (نفس التخزين، من غير نسخ ولصق):
- `index.html` **قرار شراء الخام** (الرئيسية): سعر البيع بالريال ← أعلى سعر خام ج/كجم للتعادل. الحاوية أساسي والبراد فرعي. الدولار الموحّد ونولون الحاوية وسعر الخام النهارده بيتكتبوا في القسم صاحبهم فورًا. `be-core.js` (حساب بحت + سيمبلكس + Dinkelbach) و`decision.js` (الواجهة، الحفظ `decision.v1` + mirror + IndexedDB).
- مصروفات الحاوية داخل السعودية (v2.0.1): تخليص ونقل من الميناء 6,500 + دخولية 2,000 = 8,500 ريال (`exp-migrate.js` ترحيل مرة واحدة لو عمود الحاوية لسه البنود القديمة بالظبط).
- `safi.html` **الصوافي** — نفس البرنامج القديم بكل مميزاته وحفظه (`safiNetback.v2`). الإدخالات الجديدة حاوية، 53.5 ج/$، نولون الحاوية 2,800$ (pinned.js). الحفظ القديم زي ما هو.
- `costs.html` **التكاليف** — تكاليف الموالح (`costs-core.js`/`costs-app.js` منسوخين من citrus-costs e31397f، الحساب ما اتغيرش، نفس المفتاح `citrusCosts.v2`) + `costs-io.js` استيراد مرة واحدة من البرنامج القديم (JSON أو نص COSTS1) وتصدير.
- `nav.js` شريط الأقسام + تحديث S لو القسم مفتوح في تاب تاني/رجع من bfcache.
اختبارات: `node test/be.test.js && node test/calc.test.js && node test/costs/calc.test.js && node test/costs/defaults-and-ld.test.js`؛ متصفح: `python3 -m http.server 8765` ثم `node test/merged.e2e.js && node test/sections.e2e.js` (Playwright، Chromium + WebKit). بعد تعديل CSS/HTML: `python3 build.py`.

# الصوافي
PWA offline لحساب صافي سعر البيع في السعودية راجع لمصر (العمولة، مصروفات البراد/الحاوية، النولون، المقارنة بتكلفة الطن، سعر التعادل).
الحساب (DEF / calc / _ld / f) منسوخ حرفيًا من البرنامج الأصلي (صوافي) — ممنوع تعديله. نفس مفتاح الحفظ `safiNetback.v2` (ومنقول من `safiNetback`).
المدخلات الرئيسية في `pinned.js` (تقرير 17/11/2026). البرنامج بيحفظ كل تعديل فورًا (`safiNetback.v2` + نسخة `.mirror`) وبيفتح دايمًا على آخر حفظ؛ الرجوع للمدخلات الرئيسية بزرار بس بعد تأكيد، وبيتحفظ قبلها نسخة `.beforeReset` قابلة للاسترجاع.
اختبار: `node test/calc.test.js` — بعد تعديل style.css أو index.src.html شغّل `python3 build.py` (بيحط الـ CSS والخط جوه index.html عشان الـ PDF يطلع مظبوط من غير نت).
