# الصوافي
PWA offline لحساب صافي سعر البيع في السعودية راجع لمصر (العمولة، مصروفات البراد/الحاوية، النولون، المقارنة بتكلفة الطن، سعر التعادل).
الحساب (DEF / calc / _ld / f) منسوخ حرفيًا من البرنامج الأصلي (صوافي) — ممنوع تعديله. نفس مفتاح الحفظ `safiNetback.v2` (ومنقول من `safiNetback`).
المدخلات الرئيسية في `pinned.js` (تقرير 17/11/2026). البرنامج بيحفظ كل تعديل فورًا (`safiNetback.v2` + نسخة `.mirror`) وبيفتح دايمًا على آخر حفظ؛ الرجوع للمدخلات الرئيسية بزرار بس بعد تأكيد، وبيتحفظ قبلها نسخة `.beforeReset` قابلة للاسترجاع.
اختبار: `node test/calc.test.js` — بعد تعديل style.css أو index.src.html شغّل `python3 build.py` (بيحط الـ CSS والخط جوه index.html عشان الـ PDF يطلع مظبوط من غير نت).


## الحفظ (v1.3.0)
كل تغيير بيتحفظ فورًا في localStorage (`safiNetback.v2` + `.mirror`) وفي IndexedDB (`sawafi-store`/kv: `S` و`day:<تاريخ الحساب>`). عند الفتح الأحدث بيكسب. نسخة لكل تاريخ حساب بتفضل 60 يوم (`safiNetback.v2.days` + IndexedDB) وتتفتح من «📂 الأيام المحفوظة». المؤشر «اتحفظ ✓ الساعة HH:MM». الحساب (core.js) ما اتغيرش.
